# Security Policy

## Reporting a privacy or sanitization concern

This repository is the maintainer's personal proof artifact. The sanitization contract is documented in the [README](./README.md). If you believe a file in this repository contains information that should have been sanitized (a privileged client reference, a private identifier, a financial detail), please report it privately. Do not file a public GitHub issue.

Email: **timothyshin2025@gmail.com**

You can expect an initial response within seven days. Content found to violate the sanitization contract will be removed and the repository's history rewritten if necessary.
